## 하는 일

- **문자 확인**: 의심 문자의 캡처 사진을 고르거나 문자를 붙여 넣으면 안전·주의·위험으로 판정해요. 캡처 속 글자는 휴대폰 안에서 읽고, 사진은 서버로 보내지 않아요.
- **판정 방법**: 미리 정해 둔 위험 신호와 생성형 AI 판정, 링크 평판 조회(Google Web Risk)를 함께 봐요. 링크는 열지 않고 주소만 확인해요. 판정은 판단을 돕는 참고 정보예요.
- **신고 안내**: 판정 결과에 맞는 신고 창구와 신고서 문안을 알려 줘요. 문안은 휴대폰 안에서 채우고, 신고는 본인이 창구에서 직접 해요. 앱의 '신고를 마쳤어요'는 통계용 표시일 뿐 공식 신고가 아니에요.
- **가족 보호**: 초대 번호로 가족과 연결하면, 보호받는 사람의 휴대폰에서 '위험' 판정이 나왔을 때 보호자에게 자동으로 알려요('주의'는 자동으로 알리지 않아요). '주의'·'위험' 결과에서는 보호자에게 함께 신고해 달라고 요청할 수도 있어요. 보호자에게 문자 내용은 가지 않아요.
- **공개 통계**: 판정 통계와 지금 늘고 있는 미끼(택배 사칭, 공공기관 사칭 등)를 누구나 볼 수 있는 대시보드로 보여 줄 거예요.

카카오톡 채널 챗봇, 제휴사용 판정 API, 제휴 앱이 자기 화면 안에서 여는 문자 확인 화면(웹뷰)도 만들어 두었어요.

## 개인정보를 다루는 원칙

- 가입·로그인이 없어 내 이름·전화번호·계정을 받지 않아요. 서버에는 익명 기기 ID·운영체제·알림 토큰 같은 기기 정보가 남고, 가족 보호를 쓰면 보호자가 정한 호칭(예: 엄마)과 넣은 경우 보호자 이름도 남아요.
- 문자 내용은 판정할 때만 보내고, 피싱냥 서버와 휴대폰에 저장하지 않아요. 캡처에서 글자를 읽으려고 앱이 만든 사진 사본도 다 읽은 뒤 지워요.
- 피싱냥 서버는 받은 문자를 AI·링크 검사로 보내기 전에 주민·외국인등록번호, 카드번호, 전화번호, 이메일, 계좌번호, 긴 숫자를 가려요. 목록에 없는 정보(이름, 집 주소, 생년월일 등)는 가리지 못해요. 링크는 물음표 뒤를 떼고 보내지만, 링크 주소 안에 든 번호·이메일은 가리지 못해요. 서버 로그도 같은 범위로 가려요.
- 가린 문장은 생성형 AI(Gemini API)로 보내고, Google은 정책 위반 감시를 위해 일정 기간(유료 등급은 55일) 보관해요. 카카오톡 채널로 보낸 문장은 카카오가 챗봇 통계를 위해 따로 보관해요(전화번호는 가림).
- 판정 기록에는 문자 내용과 기기 ID가 없어 누구의 기록인지 알 수 없고, 90일 뒤 지워 날짜별 집계만 남아요. 가족 보호에서 보호자에게 알림이 간 판정은 보호 알림(90일 보관)에 판정 번호·등급·미끼 유형·시각이 남아, 그동안 보호받는 사람의 기기와 이어져요.
- 서버가 준 기기 토큰(로그인 대신 쓰는 값)은 Android에서는 Keystore 키로 암호화해, iOS에서는 Keychain에 저장해요. 서버에는 해시만 남아요.
- 만 14세 미만은 기기 등록·알림·가족 보호 없이 문자 확인과 신고 안내를 써요. 개인정보로는 문자 내용과, 적었다면 보낸 번호만 피싱냥 서버에 보내요.
